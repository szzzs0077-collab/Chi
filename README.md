# Creative Coding Project – OWA OWA

Project Description

For my Creative Coding Project, I used Python in TunePad to recreate part of the song OWA OWA by Lil Tecca. My project includes three main instruments: keyboard, 808 bass and drums. The aim of this project is to explore how coding can be used to create music through different notes, rhythms and sounds.

**How My Code Works**

1. Keyboard

The keyboard creates the main melody of the song. I used two functions, phraseA() and phraseB(), to organize the musical patterns. I also used lists to play multiple MIDI notes together and for loops to repeat the phrases.

2. 808 Bass

The bass creates the lower sounds of the composition. I used a function called loop808() to organize the bass notes and their durations. A for loop repeats the pattern five times.

3. Drums

The drums create the main rhythm. I used dictionaries called loopA and loopB to play different drum sounds, including kick, snare and hihat. I also used functions, loops and conditional statements to control when each sound plays.


One of the biggest challenges was matching the notes and timing of the original song. I needed to experiment with different MIDI note numbers and beat durations to improve the sound.

Through this project, I learned how to use Python code, lists, dictionaries, loops and conditional statements to create music with code. I also improved my problem solving skills by testing and adjusting the code.

Original song: OWA OWA by Lil Tecca

Coding platform: TunePad

Programming language: Python
